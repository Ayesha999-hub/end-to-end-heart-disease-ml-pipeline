Heart Disease Prediction & Machine Learning Analysis Report

1. Introduction
The objective of this assignment was to analyze the Cleveland Heart Disease dataset and build machine learning models to predict heart disease.
One-line interpretation: This project applies full ML workflow to a real medical dataset for binary classification.

2. Dataset Description
- Dataset: Cleveland Heart Disease Dataset
- Total Samples: 303
- Features: 14 (13 input + 1 target)
- Target: 0 = No disease, 1 = Disease
One-line interpretation: A small, well-known medical dataset suitable for classification benchmarking.

3. Data Preprocessing
- Missing values handled (ca: 4, thal: 2)
- Removed rows: 6
- Final dataset: 297 rows
- Encoding + scaling applied
One-line interpretation: Cleaned and standardized data ensured models received consistent inputs.

4. Exploratory Data Analysis (EDA)
